## Этот проект демонстрирует среду, использующую Docker, включающую:

* Веб-сервер Nginx, обслуживающий статическое приложение
* Базу данных MySQL с постоянным хранилищем
* Пользовательскую сеть Docker Bridge (10.10.10.0/28)
* Оркестрацию Docker Compose

Веб-сервер доступен через порт 8080 и взаимодействует с контейнером базы данных, используя внутреннюю сеть Docker.
